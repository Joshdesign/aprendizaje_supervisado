# Aprendizaje_Supervisado
En este proyecto se realizo el análisis y limpieza de la base de datos del evento Titanic y sus pasajeros (sobrevivientes/fallecidos). Se creo un sistema de aprendizaje supervisado para una app web en la cual se pudiera visualizar la taza de porcentaje de supervivencia y fallecimiento de los pasajeros del crucero Titanic.
